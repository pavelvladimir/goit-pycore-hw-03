# Task 1

`get_days_from_today(date)` returns the number of days between a given date and today.

## Requirements covered

- input format: `YYYY-MM-DD`
- signed day difference
- no time component in the calculation
- exception handling for invalid input

## Example

```python
from goit_pycore_hw_03 import get_days_from_today

result = get_days_from_today("2021-10-09")
print(result)
```
